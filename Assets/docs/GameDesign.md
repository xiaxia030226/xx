# 🎮 游戏设计方案

---

## 📌 产品定位

> **小而精的 2.5D 卡通风格关卡制 Roguelike 割草动作游戏**
> PC 键鼠操作 | 4 角色 + 10+ 武器 | 首批 2 个关卡

---

## 🎯 核心游戏循环

```
主菜单 → 选关卡 → 进入场景
   ↓                    ↓
 天赋加点          清理预设敌人波次
   ↑                    ↓
 获得金币 ←──── 通关奖励 ←── 击败Boss ←── Boss登场
```

每次通关获得金币和经验，金币用于解锁局外天赋，经验提升角色等级。支持重复刷同一关卡。

---

## 🕹️ 操作设计

| 按键 | 功能 |
|------|------|
| `W A S D` | 角色移动（8方向） |
| `鼠标移动` | 控制角色朝向（始终面向鼠标位置） |
| `鼠标左键` | 攻击（点击单发，长按自动连发） |
| `数字键 1-9` | 切换武器（选中对应格子的武器） |
| `鼠标滚轮` | 切换武器（上一个/下一个） |
| `空格键` | 主动技能 1（每个角色独有） |
| `E 键` | 主动技能 2（部分角色拥有） |
| `Tab` | 暂停 / 查看当前Build |
| `ESC` | 暂停菜单 |

### 武器切换与 UI

屏幕下方有 9 个武器格子 UI（1-9 排列），当前选中武器高亮显示。

- 武器弹夹打空后自动切换到下一把可用武器
- 所有武器均打空时等待换弹恢复
- 每把枪有**弹夹上限**，每次射击消耗弹药，打空进入换弹，换弹结束后弹夹回满

## 👤 角色设计（单角色）

游戏只有一个玩家角色，不做过场选人。对局内通过升级三选一获得枪械配件、改装当前武器，构筑当局的 Build。

| 属性 | 值 |
|------|-----|
| 初始武器 | 普通手枪（弹夹 12，换弹 1.5s） |
| 成长方式 | 升级三选一：随机枪械配件（枪口/弹药/枪机三槽位改装） |
| 操作 | WASD 移动，鼠标朝向，左键攻击，1-9/滚轮切枪，ESC 暂停 |

> 以下为早期多角色方案存档，暂不实装，仅作未来扩展参考。
> 注意：存档中的初始武器（铁剑/短弓/火球/盾击）属于已废弃的旧武器池设计；若未来启用多角色，初始武器需重新设计为枪械。

## 🔫 武器系统（纯枪械 + 配件改装）

> 玩家每次只能使用 1 把枪，武器栏最多容纳 9 把。弹夹打空自动切换，换弹完毕可再次使用。
> 本作没有近战/法术武器，所有 Build 深度都集中在「枪械原型 × 配件改装」上。

### 枪械原型

| 编号 | 枪械 | 弹夹 | 换弹 | 伤害 | 射速 | 特点 |
|------|------|------|------|------|------|------|
| G1 | 普通手枪 | 12 | 1.5s | 10 | 点击单发 | 初始武器，稳定可靠 |
| G2 | 普通机枪 | 50 | 2.5s | 6 | 600 RPM 长按连发 | 持续火力压制 |

后续扩展原型（同一套弹夹/换弹框架，仅数值与弹道差异）：霰弹枪（扇形多弹丸）、狙击枪（慢射速高伤穿透）、冲锋枪（高射速低伤）、火箭筒（范围爆炸）。

### 配件改装（核心 Build 系统）

升级三选一不给数值强化，而是给**配件**。配件装在当前手持的枪上：

- **3 个槽位**：枪口 / 弹药 / 枪机，每把枪各槽位最多装 1 个
- **同槽位后装替换先装**：取舍就是 Build 深度
- 配件为纯数据配置（ScriptableObject），加新配件不写代码

| 槽位 | 配件 | 效果 |
|------|------|------|
| 枪口 | 双管 | 每次射 2 发（小扇形），耗 2 弹 |
| 枪口 | 三管 | 每次射 3 发（扇形），耗 3 弹 |
| 枪口 | 收束器 | 伤害 +30% |
| 枪口 | 制退器 | 射速 +25% |
| 弹药 | 穿透弹 | 子弹穿透 2 个敌人 |
| 弹药 | 爆裂弹 | 命中范围爆炸（半径 2 米，溅射 50% 伤害） |
| 弹药 | 弹射弹 | 命中后自动跳向最近的另一个敌人（1 次） |
| 弹药 | 重弹头 | 伤害 +50%，射速 -15% |
| 枪机 | 轻型枪机 | 射速 +30%，伤害 -10% |
| 枪机 | 重型枪机 | 伤害 +40%，射速 -20% |
| 枪机 | 扩容弹匣 | 弹夹 +50% |
| 枪机 | 快速装填器 | 换弹时间 -40% |

同一挺机枪可以配出霰弹流（三管）、狙击流（收束器 + 重弹头）、爆炸流（爆裂弹 + 双管）等截然不同的玩法。

## 🌟 升级选择系统

每升一级弹出 3 选 1 面板，从配件池中**随机抽取 3 个不重复配件**：

- 选项显示配件名与效果描述
- 选择后配件装入当前手持武器，同槽位自动替换旧配件
- 配件池首批 12 个（见武器系统章节），后续随新枪械原型扩充

## 🌳 局外天赋树

```
                        ┌─ 攻击力+5% ─ 攻击力+5% ─ 攻击力+10%
                        │
开局 ─ 生命值+10% ─┤─ 移速+5% ─── 移速+5% ─── 移速+10%
                        │
                        └─ 经验+5% ─── 金币+10% ── 初始武器+1级
```

总计约 12~15 个天赋节点，逐层解锁。每点消耗金币递增：100 → 200 → 500 → 1000 → ...

## 🤝 双人合作模式

- 两个角色独立操作（WASD / 方向键各自移动）
- 共享同一屏幕，镜头自动拉远适应两人距离
- 靠近时触发角色特定的组合技（如剑士+法师 = 火焰剑舞）
- 队友倒地后可走到身边按 F 救援（3秒读条）
